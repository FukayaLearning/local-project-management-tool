description: 実装されているソースコード及びテストコードから、各種ドキュメントを掘り起こす
---

## やること

* 1. フロントエンドのソースコードからのリバースエンジニアリグ
  * 1.1. フロントエンドのソースコードを解析し、抽出した設計情報と、フロントエンド設計書の設計情報記載との整合性を確認し、不整合があればフロントエンド設計書の記載を変更する。
  * 1.2. バックエンド設計書に記載変更した設計情報と、システム設計書の要件記載との整合性を確認し、不整合があればシステム設計書の記載を変更する。
* 2. バックエンドのソースコードからのリバースエンジニアリング
  * 2.1. バックエンドのソースコードを解析し、抽出した設計情報と、バックエンド設計書の設計情報記載との整合性を確認し、不整合があればバックエンド設計書の記載を変更する。
  * 2.2. フロントエンド設計書に記載変更した設計情報と、システム設計書の要件記載との整合性を確認し、不整合があればシステム設計書の記載を変更する。
* 3. システム設計書の記載変更した要件と、要求定義書の要求記載との整合性を確認し、不整合があれば要求定義書の記載を変更する。
* 4. フロントエンドの単体試験テストコードからのリバースエンジニアリング
  * 4.1. フロントエンドの単体試験テストコードから試験内容を解析し、抽出した試験内容と、フロントエンド単体試験仕様書記載との整合性を確認し、不整合があればフロントエンド単体試験仕様書の記載を変更する。
* 5. バックエンドの単体試験テストコードからのリバースエンジニアリング
  * 5.1. バックエンドの単体試験テストコードから試験内容を解析し、抽出した試験内容と、バックエンド単体試験仕様書記載との整合性を確認し、不整合があればバックエンド単体試験仕様書の記載を変更する。
* 6. 結合試験テストコードからのリバースエンジニアリング
  * 6.1. 結合試験テストコードから試験内容を解析し、抽出した試験内容と、結合試験仕様書記載との整合性を確認し、不整合があれば結合試験仕様書の記載を変更する。
