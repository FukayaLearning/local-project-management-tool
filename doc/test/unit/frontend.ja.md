# フロントエンド単体試験仕様書

## 1. テスト方針

- **ツール**: Vitest, React Testing Library
- **網羅基準**:
  - 主要なUIコンポーネント（Button, Input, Select, Modal）のレンダリングとイベントハンドリング
  - ユースケース（useTaskUseCase, useSettingsUseCase）の状態管理とAPI呼び出し
  - ページコンポーネント（TaskDetailModal, ProjectSettingsForm）のフォーム動作
