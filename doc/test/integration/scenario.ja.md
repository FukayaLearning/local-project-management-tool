# 結合試験仕様書

## 1. テスト方針

- **環境**: Dockerコンテナ環境 (Frontend + Backend + Nginx)
- **ツール**: Vitest (Frontend Integration), または Playwright (E2E)
  - 本プロジェクトでは、Frontendのコンポーネント結合テストおよび、実際にバックエンドAPIと通信する統合テストを行う。
- **目的**: フロントエンドとバックエンドが連携し、ユーザーの業務フロー（シナリオ）が正常に完了することを確認する。

## 2. テストシナリオ

### シナリオ1: プロジェクト設定の参照と更新 (Settings)

- **関連要件**: REQ-PROJ-003, REQ-SET-001
- **前提**: アプリケーションが起動しており、プロジェクトが一つ以上存在すること。

| Step | 操作/手順                                                                               | 期待される結果                                                              | Test-ID            |
| :--- | :-------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------- | :----------------- |
| 1    | プロジェクト設定ページ(`http://localhost/projects/[プロジェクト名]/settings`)にアクセス | 設定フォームが表示され、現在のプロジェクト名が表示されていること            | **IT-SCN-SET-001** |
| 2    | プロジェクト名を変更し「Save Changes」をクリック                                        | 保存完了のメッセージが表示され、プロジェクトURLも新しい名称に更新されること | **IT-SCN-SET-002** |
